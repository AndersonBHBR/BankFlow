# Contribuição

1. Crie uma branch curta a partir de `main`.
2. Preserve as fronteiras entre Contas e Transferências.
3. Adicione teste para toda nova invariante.
4. Não altere eventos publicados sem versionar o contrato.
5. Execute build, testes, lint e validação do Compose.
6. Registre decisões arquiteturais relevantes em `docs/adr`.

Commits sugeridos seguem Conventional Commits, por exemplo `feat(accounts): add scheduled limit change`.
